Асинхронный Telegram-бот, разработанный для защиты и модерации специализированного HR-сообщества (чат морских вакансий и соискателей) от скама, рекламы сомнительного заработка и флуда.

---

## 📌 Бизнес-проблематика сообществ по найму

В публичных профильных чатах вакансий рекрутеры и кандидаты регулярно сталкиваются со спам-атаками:
* Публикация мошеннических объявлений («быстрый онлайн-заработок», казино, криптокошельки).
* Несанкционированная реклама сторонних каналов через ссылки.
* Флуд и нецензурная лексика, мешающие оперативной коммуникации соискателей с координаторами.
* Засорение чата публичными сервисными командами модераторов (`/ban`, `/kick`).

**Решение:** Разработка автоматизированного бота с механизмом **«тихой модерации»**, который моментально удаляет спам и команды админов без системных следов в общей ленте.

---

## ⚙️ Функциональные возможности

* **Автоматическая фильтрация спама и скама:**
  * Подавление нежелательных триггерных слов (скам, серые схемы, казино, криптовалюты).
  * Автоудаление внешних URL-ссылок с помощью регулярных выражений (`re`).
  * Цензурирование ненормативной лексики с использованием `better-profanity`.
  * Anti-flood (Rate-limiting) с задержкой отправки сообщений от одного пользователя.
* **Скрытая панель управления модератора (`/mod`):**
  * Панель с inline-кнопками (`InlineKeyboardMarkup`) отправляется лично администратору в ЛС.
  * Быстрые действия в один клик: временный мут (5 минут, 1 час, 1 день), кик или перманентный бан.
* **Асинхронная архитектура:**
  * Библиотека `python-telegram-bot` (v20+) на базе `asyncio`.
  * Пул соединений `HTTPXRequest` с обработкой таймаутов под нагрузкой.

## 🚀 Локальный запуск

1. Клонировать репозиторий:
   ```bash
   git clone [https://github.com/](https://github.com/)<your-username>/telegram-community-moderator-bot.git
   cd telegram-community-moderator-bot
   ```
2. Установить зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Задать токен через переменную окружения и запустить:
   ```bash
   export TELEGRAM_BOT_TOKEN="ВАШ_ТОКЕН"
   python main.py
   ```
